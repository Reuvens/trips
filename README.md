# המסעות של משפחת סייג (`Reuvens/trips`) — מוח אחד לכל חופשות המשפחה

מאגר רב-טיולי (**Multi-Trip Monorepo**) המפריד באופן מלא בין **המנוע המשותף ("המוח" — `src/`)** לבין **המידע של כל טיול (`trips/<slug>/`)**, כך שכל חופשה חדשה של המשפחה מקבלת אוטומטית **שני אתרים** (אפליקציית שטח למובייל + מגזין מאויר יוקרתי), שער יורו חי וכספת הזמנות מוצפנת — ושולחן טיולים מרכזי שמארח את **כל הטיולים יחד במקביל** ב-GitHub Pages.

---

## למה ארכיטקטורת `trips/<slug>/` ב-`main` טובה יותר מפיצול ענף (`branch`) נפרד לכל טיול?

1. **כל הטיולים באוויר במקביל ב-GitHub Pages:** ב-GitHub Pages ניתן לפרוס רק מענף אחד בכל רגע. כשכל טיול יושב בתיקיית נתונים מבודדת `trips/<slug>/` תחת `main`, מקבלים גם **פורטל ראשי לכל טיולי המשפחה** (`/trips/`) וגם כתובת חיה קבועה לכל טיול (`/trips/livigno-2027/app/`, `/trips/livigno-2027/magazine/`, `/trips/next-trip/...`) בלי שאחד ידרוס את השני.
2. **שדרוג אחד במוח מעדכן את כל הטיולים (אפס קונפליקטים ב-Git):** כל תיקון עיצוב, מצב כהה, שיפור בכספת או בדיקה חדשה ב-`src/` חל אוטומטית על כל הטיולים הקיימים והעתידיים ללא צורך לעשות `git merge` בין ענפים מתפצלים.
3. **עדיין תומך בענפי טיוטה (`trip/<slug>`):** כשמתחילים לתכנן טיול חדש ועדיין לא רוצים לפרסם אותו בפורטל הראשי, פשוט פותחים ענף `git checkout -b trip/japan-2028`, מריצים `npm run new-trip japan-2028`, וממזגים ל-`main` כשהתוכנית מוכנה.

## מבנה הפרויקט

```text
trips/
├── src/                        # המוח המשותף: סכמת Zod, מנוע חישובים, הצפנת כספת, רכיבי UI ו-CSS
├── data/
│   └── rates.yaml              # שער יורו-שקל חי (מתעדכן אוטומטית מדי בוקר מה-ECB לכל הטיולים)
├── trips/                      # תיקיית נתונים מבודדת לכל טיול (אפס קוד!)
│   ├── _template/              # תבניות דוגמה לטיול חדש
│   └── livigno-2027/           # חופשת הסקי בליביניו (26.2–6.3.2027)
│       ├── trip.yaml           # מקור האמת הציבורי של הטיול (ללא מידע רגיש)
│       ├── private.example.yaml
│       ├── vault.pin.example
│       ├── private.yaml        # מוחרג ב-.gitignore! (קודי PNR, כרטיסים ו-PIN)
│       └── vault.pin           # מוחרג ב-.gitignore!
├── scripts/
│   ├── newTrip.ts              # יצירת טיול חדש בפקודה אחת: npm run new-trip <slug>
│   ├── build.ts                # בניית הפורטל הראשי + שני האתרים של כל טיול ל-dist/
│   ├── runChecks.ts            # הרצת 28 בדיקות S+V (כולל איסור דליפת סודות S1) על כל הטיולים
│   └── updateRates.ts          # עדכון שער יורו רשמי מה-ECB
└── dist/
    ├── index.html              # פורטל המסעות המשפחתי הראשי
    └── livigno-2027/           # אתר 1 (/app/) + אתר 2 (/magazine/) + דף שער לטיול ליביניו
```

## הוספת טיול חדש ב-10 שניות

```bash
npm run new-trip summer-2027
# ערכו את trips/summer-2027/trip.yaml
npm run build && npm run check && npm test && npm run test:e2e
```

## אבטחת מידע וכספת משפחתית (אפס סודות ב-Git)

- כל קובצי `trips/*/private.yaml`, `trips/*/vault.pin` ו-`trips/*/drive-vault.encrypted.json` מוחרגים ב-`.gitignore` ונאכפים אוטומטית על־ידי בדיקה **`[S1]`** גם מול `dist/` וגם מול קוד המקור והבדיקות.
- הכספת מוגנת בחשבון Google מורשה (`vaultAuth.allowedEmails` ב-`trip.yaml`) + הצפנת `PBKDF2-HMAC-SHA256` (120,000 איטרציות + תג אימות `HMAC-SHA256`).
